\begin{frame}{中间代码生成}
    遍历抽象语法树，生成中间代码

    \begin{itemize}
        \item 函数：创建函数类，并创建一个入口基本块，先给函数形参分配空间（生成alloca语句）
        \item 运算：生成加、减、乘、除、取余等指令
        \item 声明：局部的用alloca分配内存，全局的记录到全局变量中
        \item 条件：短路求值
        \item 循环、分支：根据条件语句的结果生成跳转指令，为每个分支创建基本块，再翻译每个分支
    \end{itemize}
\end{frame}

\section{编译后端}

\begin{frame}{指令选择}
哲学：
    \begin{itemize}
        \item 我是谁：这条IR指令是干啥的？
        \item 我从哪里来：指令的数据从哪来？
        \item 我要到那去：指令的结果放到哪里去？
    \end{itemize}
\end{frame}

\begin{frame}{指令选择}
操作数从哪来？
\begin{itemize}
  \item 计算
    \begin{itemize}
      \item 常量：立即数
      \item 来自别的指令的结果：寄存器
    \end{itemize}
  \item 取值：
    地址来源有  
    全局变量（通过 \texttt{la} 指令获取地址）、  
    栈帧中的局部变量（\texttt{fp} 加偏移量）、  
    数组元素（数组首地址 + 偏移量）。
  \item 存值： 
    地址来源与取值相同。
  \item 函数调用
    \begin{itemize}
      \item 调用目标：被调函数
      \item 参数来源：  
        可能是计算结果或取值结果。
    \end{itemize}
  \item 被调函数参数
    \begin{itemize}
      \item 参数寄存器：\texttt{a0-a7} 或 \texttt{fa0-fa7}
      \item 若寄存器不够：使用栈内存。超出的参数按约定由 \texttt{sp} 向高地址方向依次存放，每个槽占 8 字节（无论是 32 位整型还是 64 位指针，以 64 位对齐）。
    \end{itemize}
\end{itemize}
\end{frame}

\begin{frame}{指令选择}
指令的结果放在哪里？
\begin{itemize}
  \item 计算、取值  
    指令结果放到寄存器中，并建立 IR Value（中间表示）到 Reg（寄存器）的映射。  
    在后端翻译阶段，根据指令结果的使用位置，通过映射得到具体的寄存器。  
  \item 存值  
    将寄存器中的值写回内存。
  \item 跳转  
    执行跳转操作。
  \item 函数调用  
    参数存放位置：优先放在参数寄存器，不够时按约定放在栈上，即 \texttt{sp + 8$\times$x}（第 $x$ 个溢出参数）。  
  \item 被调函数  
    每个参数视为函数的局部变量，根据值类型（数值或指针）和对齐规则分配地址（相对于 \texttt{fp} 的偏移量），并从寄存器或栈内存搬运到被调函数的栈帧中。
\end{itemize}
\end{frame}

\begin{frame}{寄存器分配}
线扫描寄存器分配。

简单，扫描两趟。一趟扫描找（虚拟）寄存器的活跃区间，一趟扫描分配寄存器。
\end{frame}

\begin{frame}{汇编代码生成}
    以上的过程中所谓的指令、基本块、函数、模块都是一个在内存中的数据结构，汇编代码生成就是把这些信息按照汇编代码的样子组织成文本的形式。
\end{frame}

\section{编译优化}
\begin{frame}{优化框架}
    \begin{columns}
        \begin{column}{.6\linewidth}
            核心类：
            \begin{itemize}
                \item Pass;
                \item PassManager;
                \item Analysis;
                \item AnalysisManager;
            \end{itemize}

            \hspace{2em}{\fontsize{8pt}{1pt}\selectfont Pass分为变换Pass和分析Pass，变换Pass从PassManager中获取AnalysisManager并调用指定分析Pass分析IR，获得分析结果。根据分析结果执行相应的优化策略。} 

            \hspace{2em}{\fontsize{8pt}{1pt}\selectfont AnalysisManager对分析结果统一进行管理，在初次调用分析Pass，会将其返回的分析结果进行缓存，以便后续Pass获取，节省了性能；若IR进行了修改，变换Pass的run函数返回true时，或者在pass中根据需要手动作废分析结果时，AnalysisManager会清空对应缓存。}
        \end{column}
